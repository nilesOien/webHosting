GitHub Web Hosting

Given a public repo (can't be private unless you have enterprise gitHub) that contains a web page, the steps on the github repo page are :

  • Settings -> Pages (in Code and automation section)
  • Under Build and Deployment choose an Action as a source (the other option is a Branch)
  • Choose an appropriate Action template (Static HTML is the simplest one) by choosing Configure
  • Configure the yaml (often no changes are needed) and select Commit
  • The workflow will be put somewhere like .github/workflows/static.yaml so do a git pull to get it (or git pushes will fail)
  • Commit the changes to the repo with an appropriate message. This triggers page deployment.
  • Deployment history is available under Settings -> Pages
  • Subsequent pushes will trigger redeployment
For this repo (named webHosting) the web page is at https://nilesoien.github.io/webHosting and the git repo is at https://github.com/nilesOien/webHosting
